# Organizations

> Create an organization and collaborate with members in the Higgsfield API dashboard.

Organizations give your team a dedicated workspace in the Higgsfield API dashboard. Members keep their own sign-in and can switch between their personal account and any organization they belong to.

## Organization workspace

Use the account switcher in the dashboard to create an organization or move between existing organizations.
